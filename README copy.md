# ChemLab

Learn any chemical structure from a JSON dataset. Static site: no build step, works on desktop and mobile, installable as an app, works offline.

## Deploy on GitHub Pages
1. Create a repository and upload every file in this folder to the root.
2. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. Open `https://<user>.github.io/<repo>/`.

## Load your own molecules
- In the app: **Load JSON**, **Paste JSON**, or drag a file onto the page. The set and your progress are saved on the device.
- By link: put a file in the repo (e.g. `datasets/organic.json`) and open `…/?set=datasets/organic.json`.
- Format and AI prompt: see `chemlabguide.md`.

## Mobile
Add to Home Screen (iOS Safari: Share → Add to Home Screen; Android Chrome: menu → Install app). Use the tool bar under the canvas: Draw, Select/Move, Inspect, Erase.
